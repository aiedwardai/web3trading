# 执行手册：日/周/月监控 + 打分卡 + 数据源速查

---

## 每日监控（约 5 分钟）

- [ ] **BTC/ETH 现货量** vs 30 天均值（缩量 = 动能不足）
- [ ] **美 / 亚 / 欧 CEX 净流量**（CoinGlass / Glassnode）
- [ ] **散户交易需求**（<$10k 钱包 BTC 交易变化 %）
- [ ] **年化融资率 / 3M 基差**（多空意愿）
- [ ] **稳定币市值 vs CEX 买盘规模**（资金入场同步性）
- [ ] **恐贪指数**（alternative.me）
- [ ] **交易所净流 / 余额**（LookNode 免费层）
- [ ] **ETF 日度净流入**（SoSoValue / Farside）

## 每周复盘（约 30 分钟）

- [ ] **URPD DIFF 版**：上方红色是否扩大？下方绿色是否承接？
- [ ] **鲸鱼地址群组**：1k–10k BTC、1k–10k ETH、≥10k SOL 数量变化
- [ ] **LTH / STH 持仓供应**：LTH 是否继续创新高 / 首次减仓？
- [ ] **UTXO 能量带**：各成本区间的周度抛售 / 购入量
- [ ] **利润供应 %**：是否回落到 <50%（抄底）或冲上 >95%（顶部）？
- [ ] **已实现利润单日峰值**：是否突破 10 亿？
- [ ] **LTH 30 天日均获利**：是否 >10 亿？与 STH 差距是否 >3 倍？
- [ ] **币龄 >2Y 持币者止盈规模**
- [ ] **SOPR / LTH-SOPR**：是否跌破 0.9（投降）
- [ ] **MA200 斜率**（趋势过滤是否通过）

## 每月深度（约 2 小时）

- [ ] **MVRV Pricing Bands**：价格所处带位（0.6 / 1.0 / 2.4 / 3.2 RP）
- [ ] **MVRV Z-Score**：是否 >3 进入顶部区
- [ ] **NUPL 长 / 短分拆**：是否同步进入贪婪
- [ ] **Ahr999**：是否进入定投区 / 抄底区
- [ ] **交易所余额**：60 天净流入规模
- [ ] **期权 OI / Put-Call / 中远期 Put 倒挂**
- [ ] **ETF 净流入 vs 价格**：是否出现"拉盘 + 利好"掩护出货
- [ ] **美联储利率概率 + 10 年美债 + DXY**
- [ ] **基本面事件**：回购机制、监管、上市计划等逻辑存续性检查
- [ ] **相对价值扫描**：组合内各标的 MVRV Z / 泡沫倍数横向排名

## 决策打分卡（模板，可复制使用）

```
标的：______    日期：______    价格：______    MA200 斜率：______（>0 才允许抄底）

【D1 估值】□ MVRV<1.0  □ MVRV Z<0  □ NUPL<0.25  □ Ahr999≤0.45  □ 利润供应<50%
          □ 价格<1.0RP        → 小计 ___/6
【D2 筹码】□ 下方 URPD 绿  □ LTH 创新高  □ 价格站上 STH 成本  □ 远端惜售
          □ 交易所余额下降              → 小计 ___/5
【D3 主力】□ 鲸鱼净流入高分位  □ 价↓鲸鱼地址↑  □ 投降盘已释放  □ ETF 持续正
          □ SOPR 企稳                  → 小计 ___/5
【D4 情绪】□ 稳定币扩张  □ 现货量回升  □ 分区域情绪转正  □ 恐贪<25 或合理
          □ 活跃地址回升               → 小计 ___/5
【D5 衍生】□ 费率温和  □ OI 未过热  □ 无 Put 倒挂          → 小计 ___/3
【D6 宏观】□ 降息/宽松  □ 美债回落  □ 无重大事件风险        → 小计 ___/3

抄底判定：D1≥2 且 总触发≥3 且 MA200 斜率>0 → 建仓 20%×触发项
逃顶判定：(MVRV Z>3 或 NUPL>0.75 或 利润供应>95%) 且 派发类触发≥3 → 减 25%
```

> 可用 `scripts/onchain_scorecard.py` 自动计算（支持 `--demo` 与 `--input metrics.json`）。

### 取数避坑

- **LookNode 必须用 www 域名**
- **交易所端点要加 `?ex=all`**
- 被墙的源不要反复重试，直接换源或标注 N/A
- 付费指标拿不到时明确写 N/A，并用代理指标 + 趋势过滤兜底
