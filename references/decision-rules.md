## 规则系统 A · 抄底（买入）

### 前置过滤（必做，回测修正 1）

> **MA200 自身 30 日斜率 > 0。不满足，则不采纳任何抄底信号。**
> 下降趋势里"便宜"会一直便宜——2025-10 之后所有未过此过滤的抄底信号全部亏损（跌幅 -17% ~ -32%）。

### 触发项（满足 ≥3 项才进场，每满足一项加 20% 仓位）

| # | 触发条件 | 维度 | 案例出处 |
|---|---|---|---|
| 1 | **MVRV 跌破 0.6 RP 下轨** 或 **Ahr999 ≤ 0.45** | D1 | ETH 2025-04-19（$1,585，90 天 +118.9%） |
| 2 | **利润供应 % < 50%**（最好 <45%） | D1 | 2018 / 2022 底部特征 |
| 3 | **MVRV Z < 0** 且 **NUPL < 0.25** | D1 | 极端估值共振 |
| 4 | **鲸鱼群组净流入创新高**（单日 > 历史 99 分位） | D3 | ETH 2025-06-12 +871K |
| 5 | **鲸鱼地址数↑ + 价格↓ 背离** | D3 | SOL 2025-06 地址 5,114 vs 价 $152.98 |
| 6 | **某区域资金情绪率先转正**（欧区先正 → 美/亚跟进） | D4 | SOL 2025-06 |
| 7 | **散户交易需求见底回升 + 现货量企稳** | D4 | — |
| 8 | **投降盘集中释放**（单日已实现亏损爆量后转净盈利） | D3 | BTC 2026-09-04 亏损 $1.64B |
| 9 | **价格深跌 + 期权玩家一边倒买看跌**（恐慌极值） | D2/D5 | BTC 2025-04-09（$76,291，90 天 +42.0%） |

### 仓位规则

```
过滤不通过        → 0 仓位（只允许"定投区"小额分批，见规则 C）
满足 3 项         → 20% × 3 = 60%... 按原规则每项 20%，3 项起步
满足 4 项         → +20%
满足 5 项+        → +20%（上限 100%，但建议留 20% 现金应对二次探底）
```

**纪律**：
- 不满 3 项坚决不动
- 分批执行，不一次打满
- ETF 流入 / 资金费率 / 新闻**不构成信号**，只作催化

### 分批规则（回测修正 2，**永不一次清仓**）

```
触发 3 项  → 减 25%
触发 4 项  → 再减 25%
触发 5 项+ → 再减 25%
永远保留 25% 底仓（直到趋势过滤也翻空 / 真实逃顶信号触发）
```

**回测依据**：ETH 2025-06-11 触发后仍涨 53%（60 天 +51.7%、90 天 +53.2%），一次性清仓会踏空整个波段。

**核心理念**：顶部信号告诉你"趋势成熟"，**不告诉你"明天见顶"**。领先时间可能长达 2–3 个月。

## 规则系统 D · 相对价值换仓（BNB 案例提炼为通用规则）

> **这是本框架真正的 alpha 来源**（回测：BNB→BTC 90 天 -29.8%，超额约 19pp）。

### 通用触发条件（满足 ≥3 项即考虑换入更抗跌标的）

| # | 条件 | 检查方式 |
|---|---|---|
| 1 | **估值倍数量级差异** | A 标的 MVRV Z 3.6 vs B 标的 0.85 —— 量级差异，不是估计误差 |
| 2 | **筹码向交易所堆积** | 交易所余额 60 天净流入规模（BNB：464 万枚 / 60 亿美金） |
| 3 | **全市场浮盈（长短持双双盈利）** | LTH NUPL 处于 Euphoria–Greed + STH NUPL 0.2–0.3 |
| 4 | **基本面估值透支** | 市值 / 年化利润（BNB：50 倍 vs 回购可支撑的 20 倍） |
| 5 | **核心逻辑存在终止风险** | BNB：币安赴美上市 → 回购终止（参照 OKB / X Layer） |
| 6 | **K 线赶顶形态** | 突破前高 + 极端乖离（远离 MA60）+ 泡沫值 202% + **无量拉升** |
| 7 | **活跃度未验证价格** | 活跃地址数未破前高 / 交易量萎缩 |

### 执行要点

- **不需要预测绝对方向**，只需比较"哪个更贵、哪个更抗跌"——这是链上数据最能回答的问题
- **换仓后保留原标的观察**：BNB 下方支撑 835 / 553（URPD 峰）作为再评估参考位
- **同类判断可扩展**：高 beta alt vs BTC、BTC vs 稳定币，逻辑一致

## 禁用清单（回测证伪项）

| 禁用项 | 原因 |
|---|---|
| **绝对目标价** | "BTC 至少 $130K–150K" 落空（ATH 停在 126,198）。框架能答"贵不贵""主力在干嘛"，答不了"能涨到多少"——后者依赖不可预测的增量资金 |
| **无趋势过滤的抄底信号** | 代理版无过滤胜率 50–56% ≈ 随机 |
| **代理版逃顶信号** | 30/60/90 天胜率 50%/38%/50% ≈ 随机。**逃顶必须用真实指标** |
| **一次性清仓** | ETH 案例证明领先时间可达 2–3 个月 |
| **把 STH 成本线跌破当清仓触发** | BTC 2025-02-25 跌破后 90 天反而 +19.2%。只当**减仓触发** |

## 风控与仓位管理

| 状态 | 权益仓位 | 说明 |
|---|---|---|
| 抄底信号 ≥3 项 + 趋势过滤通过 | 60–80% | 分 3 批建，每批间隔 ≥1 周 |
| 定投区（估值便宜 + 趋势未确认） | 10–30% | 小额定投，禁止趋势加仓 |
| 中性区 | 30–50% | 持有，网格策略可选 |
| 逃顶触发 3 项 | -25% | 第一批减仓 |
| 逃顶触发 4 项 | -25% | 第二批 |
| 逃顶触发 5 项+ | -25% | 第三批，**保留 25% 底仓** |
| 趋势过滤翻空（MA200 斜率 <0） | 禁止新建仓 | 只允许定投 |

### 单标的与集中度

- 主流币（BTC/ETH）为主，单一 alt 仓位上限 20%
- 出现"相对价值换仓"信号时，**换入 MVRV Z 显著更低、基本面逻辑未受损的标的**
- 保留不低于 20% 的稳定币应对二次探底

### 认知偏误清单

| 偏误 | 表现 | 对冲 |
|---|---|---|
| 锚定目标价 | "BTC 至少 130K" | **已禁用** |
| 确认偏误 | 只看支持自己持仓的指标 | 强制走完六维打分卡 |
| 叙事驱动 | 被 ETF 利好、大佬喊单带节奏 | 利好 + 拉盘同步 = 掩护出货信号 |
| 线性外推 | "稳定币增长 = 要涨" | 场外有钱 ≠ 买盘 |
| 抄底急躁 | 一下跌就买 | 前置过滤：MA200 斜率 >0 |
| 逃顶急躁 | 一涨就清 | 分批 25%，永不清零 |

### 三句心法

1. **底部靠估值 + 主力确认，顶部靠行为 + 情绪确认。**
2. **ETF / 资金费率 / 新闻是催化，不是信号。**
3. **波动是入场券，纪律才是护城河。**
