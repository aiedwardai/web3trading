## D2 · 筹码结构（谁拿了多少、成本在哪）

|---|---|---|
| **URPD（已实现价格分布）** | 红色柱 = 筹码减少（派发）；绿色虚线 = 新增筹码 | 上方红色 = 抛压；下方绿色 = 承接。BNB 两大峰 **553 / 835** |

## D4 · 资金情绪（钱从哪儿来、热情还在吗）

| 工具 | 关键读数 / 阈值 | 用法 |
|---|---|---|
| **分区域资金情绪** | 美 / 亚 / 欧 CEX 净流量 | **价格↑情绪↓ = 背离（危险）**；欧区率先转正 = 先行指标；美区回落 + 亚区上升 = 反指 |
| **稳定币市值 vs CEX 买盘** | 两者是否同步扩张 | 稳定币↑ 而买盘未同步 = 场外有钱没进场。2025 年 $170B→$220B 而 CEX 净流入持续收缩 |
| **稳定币转账量 vs 市值** | 市值停滞 + 转账量暴增 = 存量空转 | 2026-09：市值 90 日 -0.9%，转账量 +48.83% |
| **BTC 现货交易量** | vs 30 日均值 / 历史同期 | 缩量 = 动能不足。2025 年多期"异常低迷"；2026-09 链上成交额 30 日 **-63%** |
| **散户交易需求** | <$10k 钱包 BTC 交易变化 % | 下降 >5% + 现货量创新低 = 缺乏新增需求 |
| **链上活跃地址** | 30 日变化 % | 价格新高但活跃地址未破前高 = 使用增长未同步（BNB 案例） |
| **mempool 费率** | sat/vB | 极低 = 链上需求清淡 |
| **贪婪与恐惧指数** | <25 极度恐惧（机会）；>75 极度贪婪（末端） | "高情绪、低动能" = 上行势能减弱 |
| **BTC Dominance** | 上升 + ETH 跑赢 = 加密内部轮动 | 风险偏好回升但稀释 BTC 相对买盘 |

## UWeb 七条心法（17 期反复验证）

| # | 心法 | 含义 |
|---|---|---|
| 1 | **高情绪、低动能 = 顶部预警** | 恐贪高位 + 现货量低迷 = 上行势能边际减弱 |
| 2 | **投机主导、长期惜售 = 健康洗盘** | NRPL 高位但远端筹码不动 = 非趋势反转 |
| 3 | **美区情绪回落 + 亚区情绪上升 = 反指信号** | 美洲被视为先行指标，亚洲常为反向指标 |
| 4 | **ETF 单周方向 = 短期见顶指标** | 由持续流入转单周大额流出 = 警报 |
| 5 | **降息预期悲观 = 短期承压；降息兑现 = 利好兑现可能见顶** | 宏观的反身性 |
| 6 | **主升浪启动条件 = 资金入场 + 需求扩张同步** | 稳定币增长 ≠ 买盘增长 |
| 7 | **LTH 持仓创新高 = 主升浪渐近；LTH 集中派发 = 顶部信号** | 但须结合价格位置判断（牛市减仓 = 顶部；熊市后段减仓 = 解套兑现） |
